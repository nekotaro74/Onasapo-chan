# Onasapo-chan 更新履歴

このアプリの更新案内です。PWA 内の「更新内容」リンクは本書の GitHub Pages 版（<https://nekotaro74.github.io/Onasapo-chan/docs/更新履歴.html>）を開きます。実装の仕組みなど開発向けの詳細は [開発変更履歴.md](開発変更履歴.md)（GitHub Pages 版: <https://nekotaro74.github.io/Onasapo-chan/docs/開発変更履歴.html>）に載せています。

フォーク元リポジトリ [Gemini PWA](https://github.com/titan823/geminipwa) 由来の履歴は README.md に残しています。更新を書くときは本書の**最新が上**になるよう追記し、`sw.js` の `CACHE_NAME` を上げてください。

### 2026-10-14（バージョン 0.27on (Onasapo-chan)）
- **アプリの更新をお知らせするバナーの色を見直しました。** これまでヘッダーと同じ色で、文字が読みにくいテーマがありました。どのテーマでも読みやすい配色にしています。
- **同じ会話セッションを別のタブで開いているとき、保存する前に確かめるようにしました。** 後から保存した側が、先に保存した側で追加した挿絵などを消してしまうことがありました。確認で「キャンセル」を選ぶと上書きせず、他のタブが保存した内容を開き直します。
- **同じタブでリトライするたびに、上の確認が出ていた不具合を直しました。**

### 2026-10-13（バージョン 0.27on (Onasapo-chan)）
- **アプリの更新をお知らせするバナーを追加しました。** チャット・履歴・設定の各画面の上部に出ます。**更新する** を押すまで新しい版は適用されないので、作業中に勝手に再読み込みされることはありません。
- **挿絵生成用プロンプトの既定文を微調整しました。** すでに自分で編集している人はそのまま残ります。新しい文章にしたい場合は、その下の**既定に戻す**を押してください。

### 2026-10-12（バージョン 0.27on (Onasapo-chan)）
- **挿絵生成用プロンプトの既定文を、日本語の指示文へ差し替えました**（書き出されるタグはこれまでどおり英語です）。編集している人はそのまま残ります。新しい文章にしたい場合は**既定に戻す**を押してください。

### 2026-10-11（バージョン 0.27on (Onasapo-chan)）
- **挿絵生成用プロンプトの既定文を更新しました。** 出力の長さとタグの書き方を整理しています。
- **読み上げ中の応答を削除すると、再生がその場で止まるようにしました。** まだ合成していない文を TTS サーバーに作らせないため、削除後に無駄な読み上げが続くことがありません。
- **Irodori 以外の OpenAI 互換 TTS サーバーでも読み上げが壊れないようにしました。**
- **設定の「LoRA（最大4個）」の注釈を見直しました。** どのワークフロー向けの説明か分かるようにしています。
- **DeepSeek の「Max Tokens」の上限に、既定 32768 が入るようにしました。** スライダーを少し動かしただけで現実的でない値が入ることはありませんでした。
- **読み上げの「速度」に直接入力欄を付けました。** 0.05 刻みで細かく合わせやすくなります。

### 2026-10-10（バージョン 0.27on (Onasapo-chan)）
- **挿絵生成に送る会話履歴は、既定で全件送信にしました。** 範囲から外れた登場人物の外見が効かず、絵の人物が崩れることがありました。長い会話で絞りたくなったら「挿絵生成の推論に使う履歴の上限(文字数)」を設定できます。
- **設定の注釈を短い表現にまとめ、導入手引きへの案内はクリックで開くリンクにしました。**
- **LoRA を「使用中」にした時点で選べるようにしました。** これまで「接続確認＆モデル一覧取得」を押すまでプルダウンが無効でした。
- **GPU の VRAM の目安**を導入手引きと README に追記しました。

### 2026-10-09（バージョン 0.27on (Onasapo-chan)）
- 設定の「モデル選択と生成パラメータ」にある一覧取得の注釈を、画面から見える表現に書き換えました。

### 2026-10-06（バージョン 0.27on (Onasapo-chan)）
- **DeepSeek を刷新しました。** 接続先を `https://api.deepseek.com` への直接接続に変更し、**Thinking Mode** と **Reasoning Effort** の設定を追加しました。
- **Service Worker がローカル・LAN・Tailscale 宛の要求を横取りしないよう変更しました。** GitHub Pages から挿絵生成・読み上げを使う手順を README に追加しています。
- **挿絵生成と読み上げの導入手引きを [docs/挿絵生成と読み上げの導入手引き.md](挿絵生成と読み上げの導入手引き.md) として正本化しました。**
- **アプリ名と URL を Onasapo-chan へ変更しました。**
