# 挿絵生成と読み上げの導入手引き

挿絵生成（ComfyUI）と読み上げ（Irodori TTS Server などの OpenAI 互換 TTS）を初めて使う方向けの手順です。このファイルが**正本**で、README と PWA 内の短い手順はここと同じ内容になっています。

## 1. 全体像

このアプリには中継サーバーがありません。ブラウザ（PWA）が、**あなたの PC で起動している ComfyUI と TTS サーバーへ直接**つなぎに行きます。

```
スマホ / PC のブラウザ（PWA）
        │  http://
        ├──→ ComfyUI        （PC で起動、ポート 8188）  … 挿絵生成
        └──→ Irodori TTS    （PC で起動、ポート 8088）  … 読み上げ
```

したがって必要なのは、**その 2 つを PC で起動しておくこと**と、**ブラウザからそこに届くこと**だけです。

### VRAM の目安

画像生成はモデルによりますが、既定の Anima Base なら **6GB**、読み上げは Irodori-TTS-v4.1-Small の `int8` 量子化で **4GB** が目安です。

- 挿絵と読み上げの**タイミングをずらす**（同時に動かさない）なら **6～8GB程度**
- **同時に動かす**なら **10GB** が最低ライン、**12GB** あれば安心
- VRAM が足りない PC でも、Irodori-TTS-v4.1-Small は近年の PC なら CPU 版でもステップ数を下げるなどすれば意外とそこそこ動きます（作者の実測）

## 2. 使い方のパターンを決める

| パターン | 必要な設定 |
| --- | --- |
| **A. ComfyUI を動かしている PC のブラウザで使う** | サーバーの起動設定と、PWA への URL 入力だけ |
| **B. スマホや別 PC から使う** | A に加えて **PC とスマホの両方に Tailscale** |

パターン A だけで使う場合、第 3 章（Tailscale）は読み飛ばしてください。

PC で開くページは GitHub Pages（<https://nekotaro74.github.io/Onasapo-chan/#chat>）でも、`__winlocal.bat` によるローカル起動でも構いません。

## 3. Tailscale を準備する（スマホ・別 PC から使う場合）

Tailscale は **PC とスマホの両方**にインストールします。どちらか片方だけでは繋がりません。

1. **PC に入れる**：<https://tailscale.com/download>（Windows では Microsoft Store 版でも可）からインストールし、アカウントでログインします。
2. **スマホに入れる**：Play Store / App Store で「Tailscale」を検索してインストールし、**PC と同じアカウント**でログインします。
3. Tailscale の一覧（tailnet）に **PC とスマホの 2 台が並んでいる**ことを確認します。
4. **PC の Tailscale IP を控えます**。`100.` で始まる 4 つの数字です。
   - タスクバーの Tailscale アイコンを開く、または
   - コマンドプロンプトで `tailscale ip -4`

この IP が、この先 `{Tailscale IP}` と書いている箇所に入ります。PC を買い替えたり端末を入れ替えたりすると IP は変わるので、そのときは PWA に入力した URL と `.env` の 1 行も書き直してください。

## 4. 挿絵生成（ComfyUI）

### 4.1 起動オプションを付ける

```
--listen 127.0.0.1,{Tailscale IP} --enable-cors-header
```

- `{Tailscale IP}` は PC の Tailscale IP に読み替えます。
- **PC だけで使うなら `--enable-cors-header` だけで構いません。** ComfyUI は既定で `127.0.0.1` しか待ち受けないため、`--listen` を付けないと Tailscale のアドレスにパケットが届きません。
- `--listen 127.0.0.1,{Tailscale IP}` は全インターフェースではなく、**その PC と Tailscale 側だけに開く**指定です。

⚠️⚠️⚠️⚠️⚠️ ComfyUI には認証がありません。ルーターでポート 8188 をインターネットへ転送するなど、外向きに開く設定は避けてください。

### 4.2 PWA に入力する

1. 設定（⚙️）→「挿絵生成（ComfyUI）」を開きます。
2. 「ComfyUI base URL」を入力します。

   | 使う場所 | ComfyUI base URL |
   | --- | --- |
   | PCだけで使う | `http://127.0.0.1:8188` |
   | スマホや別PCから Tailscale 経由で使う | `http://{Tailscale IP}:8188` |

3. **「接続確認＆モデル一覧取得」**を押します。「接続OK」が出たあと、モデル / VAE / テキストエンコーダ / Sampling method / Scheduler / LoRA がプルダウンに並びます。
4. 生成パラメータ（Steps / CFG scale / 幅・高さ / Denoise / CLIP Skip / Seed）を埋めます。既定値は Anima / SDXL 向けです。
5. ワークフローは**同梱の規定ワークフロー**が最初から入っています。自分のを使う場合は **API 形式**の JSON を貼り付けます（`nodes` / `links` を持つ UI 形式は使えません）。
6. 生成タイミングを自動 / 手動で選びます。入力欄付近の `絵:自動` / `絵:手動` / `絵` ボタンからも操作できます。

## 5. 読み上げ（Irodori TTS Server）

### 5.1 `.env` に CORS を追記する

Irodori TTS Server フォルダ直下の `.env` をテキストエディタで開き、「# Server」項の最終行に次を追加します。

```
IRODORI_CORS_ORIGINS=["http://localhost:8072","http://127.0.0.1:8072","http://{Tailscale IP}:8072","https://nekotaro74.github.io"]
```

- `{Tailscale IP}` は PC の Tailscale IP に読み替えます。
- 追加したら **Irodori を再起動**します（`.env` は起動時にしか読まれません）。
- 上の 1 行は「GitHub Pages から / `__winlocal.bat` のローカル起動 / Tailscale 経由」を全部許可した安全側の設定です。PC だけで GitHub Pages のページを使うなら `https://nekotaro74.github.io` だけでも動きます。

### 5.2 PWA に入力する

1. 設定（⚙️）→「読み上げ（TTS）」を開き、「読み上げを有効にする」をオンにします。
2. エンドポイントを入力します。

   | 使う場所 | エンドポイント |
   | --- | --- |
   | PCだけで使う | `http://127.0.0.1:8088/v1` |
   | スマホや別PCから Tailscale 経由で使う | `http://{Tailscale IP}:8088/v1` |

   末尾に `/audio/speech` が無ければアプリが自動で足します。APIキーは通常不要で、空なら `Authorization` を送りません。
3. **「接続確認＆ボイス一覧取得」**を押します。Irodori の Voices フォルダの中身がチェックボックスに並び、**チェックした物だけが話者選択の候補**になります。
   - 一覧に `latent` や `SI` も並ぶのは、Irodori が Voices フォルダの `*.pt` / `*.speaker.safetensors` を voice として登録するためです。`no_ref` は Voice Design 用なので既定で有効になりません。
   - 一覧 API を持たないサーバーでは「接続OK（…非対応の可能性）」と表示され、閉じた **「詳細（参照ボイス一覧を手で編集する）」** でカンマ区切り入力できます。
   - 一覧を取りに行くのはボタンを押したときだけです。5 分以内の再取得はキャッシュを使い、ボタンは毎回取り直します。
4. 隣の **「テスト再生」** で実際の音を確かめます。読み上げキューとは別に鳴り、「停止」は対象外です。
5. 話者割当を設定します。デフォルトボイス＝地の文、汎用ボイス＝話者名の無い引用や括弧、登場人物 1〜5 に名前とボイスを割り当てます。
6. 速度はスライダー 0.25〜4.00 倍。自動読み上げの入力欄付近のメガホンボタンは **自動が赤地に白**、**手動がグレー地に白**です。

## 6. ブラウザの許可を出す

Chrome 系では、公開ページからローカルアドレスへ接続するとき「**ローカルネットワークへの接続**」の許可ダイアログが出ます。**許可しないと接続確認は失敗します。**

https のページから `http://127.0.0.1` やプライベートアドレスへ送る要求は、mixed content としてブロックされません。

## 7. つまずいたときの確認

| 症状 | 見る場所 |
| --- | --- |
| 挿絵の接続確認が失敗する | ComfyUI が起動しているか / `--enable-cors-header` を付けたか / base URL のポートが 8188 か / ブラウザの許可を出したか |
| Tailscale 経由だけ失敗する | ComfyUI に `--listen 127.0.0.1,{Tailscale IP}` を付けたか（既定は `127.0.0.1` のみ） |
| 読み上げの接続確認が失敗する | `.env` の `IRODORI_CORS_ORIGINS` にオリジンが入っているか / 追加後に Irodori を再起動したか / ポートが 8088 か / URL の末尾が `/v1` か |
| スマホだけ失敗する | **PC にも Tailscale が入っていてログインしているか** / 2 台が同じ tailnet にいるか / PC の Tailscale IP が変わっていないか |
| 接続できるが画像が出ない | ワークフローが API 形式か / 未対応プレースホルダのエラー表示が出ていないか |
| 更新が反映されない | 設定の「アプリを更新 (キャッシュクリア)」で Service Worker のキャッシュを取り直す |

## 8. 実測記録（2026-10-06）

スマホ（Tailscale 経由）で確認しました。

- **挿絵生成**：`--enable-cors-header` および、`--listen` を付けた起動で接続・生成に成功しました。
- **読み上げ**：`IRODORI_CORS_ORIGINS` に `https://nekotaro74.github.io` を含めた Irodori に対して、`http://{Tailscale IP}:8088/v1/audio/speech` で接続確認・読み上げに成功しました。
- **起動オプション**：`--listen 127.0.0.1,{Tailscale IP} --enable-cors-header` で起動した ComfyUI に対し、同一PC（`__winlocal.bat`）と Android の Chrome（Tailscale 経由）の両方から接続・動作を確認済みです。
