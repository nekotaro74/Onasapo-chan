# 挿絵生成と読み上げの導入手引き

このファイルが**正本**です。README の案内文と、PWA 内の「挿絵生成（ComfyUI）」「読み上げ（TTS）」に置いてある短い手順は、すべてここと同じ手順・同じコマンド・同じ注意にします。

## 最初に：スマホから使うには Tailscale が必要

外出先のスマホで挿絵生成と読み上げを使うには、そのスマホに **Tailscale をインストールし、自宅PCと同じ Tailscale ネットワークへ参加**させてください。Tailscale が無ければ、外出先のスマホから自宅PCの ComfyUI と Irodori TTS Server には届きません。

## 挿絵生成（ComfyUI）

### ComfyUI の起動オプション

```
--listen 127.0.0.1,{Tailscale IP} --enable-cors-header
```

`{Tailscale IP}` は自宅PCの Tailscale IP に読み替えてください。

これは全インターフェースではなく、**このPCと Tailscale 側だけに開く**指定です。ComfyUI に認証は無いため、ルーターで 8188 をインターネットへ転送しないでください。

### PWA の ComfyUI base URL

使う場所で次のように分けます。

| 使う場所 | ComfyUI base URL |
| --- | --- |
| PCだけで使う | `http://127.0.0.1:8188` |
| スマホや別PCから Tailscale 経由で使う | `http://{Tailscale IP}:8188` |

## 読み上げ（Irodori TTS Server）

### `.env` の設定

Irodori TTS Server フォルダ直下の `.env` をテキストエディタで開きます。「# Server」の最終行に次を追加してください。

```
IRODORI_CORS_ORIGINS=["http://localhost:8072","http://127.0.0.1:8072","http://{Tailscale IP}:8072","https://nekotaro74.github.io"]
```

`{Tailscale IP}` は自宅PCの Tailscale IP に読み替えてください。追加したら **Irodori を再起動**します。

### PWA のエンドポイント

使う場所で次のように分けます。

| 使う場所 | エンドポイント |
| --- | --- |
| PCだけで使う | `http://127.0.0.1:8088/v1` |
| スマホや別PCから Tailscale 経由で使う | `http://{Tailscale IP}:8088/v1` |

末尾に `/audio/speech` が無ければアプリが自動で足します。APIキーは通常不要で、空なら `Authorization` を送りません。

### 参照ボイス一覧の取得

設定の **「接続確認＆ボイス一覧取得」** を押すと、Irodori の `GET /v1/audio/voices` を叩いて Voices フォルダの中身をチェックボックスに並べます。**チェックした物だけが話者選択の候補**です。

- 一覧 API への要求がそのまま接続確認を兼ねます。Irodori 固有の `/health` は使いません（他の OpenAI Compatible サーバーでも壊れないようにするため）。
- 一覧に `latent` や `SI`（Speaker Inversion）も並ぶのは、Irodori が Voices フォルダの `*.pt` / `*.speaker.safetensors` を voice として登録するためです。`no_ref` は Voice Design 用なので、既定で有効にはしません。
- 一覧を返さないサーバーでは「接続OK（…非対応の可能性）」と表示し、閉じた **「詳細（参照ボイス一覧を手で編集する）」** のカンマ区切り入力で従来どおり編集できます。
- 一覧を取りに行くのはボタンを押したときだけです（設定を開いたときの自動取得はありません）。5 分以内の再取得はキャッシュを使い、ボタンは毎回取り直します。
- 実際の音を確かめたいときは隣の **「テスト再生」** を押します。読み上げキューとは別に鳴り、「停止」は対象外です。

## ブラウザの許可

Chrome 系では、公開ページからローカルアドレスへ接続するとき「ローカルネットワークへの接続」の許可が出ます。**許可しないと接続確認は失敗します。**

https のページから `http://127.0.0.1` やプライベートアドレスへ送る要求は、mixed content としてブロックされません。

## 実測記録（2026-10-06）

外出先のスマホ（Tailscale 経由）で確認しました。

- **挿絵生成**：`--enable-cors-header` だけでは接続できず、`--listen` を付けた起動で接続・生成に成功しました（既定の待受先が `127.0.0.1` のため、Tailscale のアドレスにパケットが届きません）。
- **読み上げ**：`IRODORI_CORS_ORIGINS` に `https://nekotaro74.github.io` を含めた Irodori に対して、`http://{Tailscale IP}:8088/v1/audio/speech` で接続確認・読み上げに成功しました。
- **起動オプション**：`--listen 127.0.0.1,{Tailscale IP} --enable-cors-header` で起動した ComfyUI に対し、同一PC（`__winlocal.bat`）と Android の Chrome（Tailscale 経由）の両方から接続・動作を確認済みです。
